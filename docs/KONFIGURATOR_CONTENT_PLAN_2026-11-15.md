# Konfigurator — план реализации и источники

Дата: 15.11.2026. Локальная презентационная доработка существующего KLOTZ.

## Сценарии и коммерческая польза

- Канонический /konfigurator объединяет подготовку Haustür и Energiesparrechner. Ссылка доступна в основной навигации, мобильном меню, footer и из профильных оконных/дверных материалов.
- По D-041 сокращённая студия заменена реальным каталогом: 503 варианта / 134 семейства, девять коллекций, 199 поверхностей, восемь форм, поиск, сравнение, избранное и размеры. 427 собственных фото, 73 явно отмеченных базовых иллюстрации, три без изображения. Исходные фотографии не деформируются/не перекрашиваются: пожелания цвета показаны образцами, габариты — отдельной схемой. Проверка модельных Min/Max не заменяет техническую системную проверку. Полный оригинал доступен по ссылке и через iframe только по явному клику. Внешний режим не принимает локальный план автоматически.
- Локальный расчёт сравнивает трансмиссионные теплопотери указанной площади окон. Uw, площадь, Gradtagzahl, отопление, коэффициент и необязательный тариф редактируются. Отдельно показываются тепло, конечная энергия и условная денежная разница. Не выводятся гарантированная экономия всего дома, окупаемость, CO2 и субсидии.
- Выбранные параметры можно передать в существующую демо-заявку. Только известные значения/числовые диапазоны; сервер повторно проверяет их и вычисляет результат. Angebote и известные услуги сохраняют приоритет. Личных данных в инструментах нет.

## Проверенные источники

1. https://konfigurator.klotz.mobi/ — HTTP 200 по HTTPS. Дверной каталог на системе производителя; HTML содержит внешние библиотеки, GA, PDF/заявку и privacy-ссылку ADORO. Код, цены, награды и технологические/CNC-данные не копируются. Из публичных GET импортируются только каталоговые названия, размерные рамки, поверхности и иллюстрации с provenance. Встроенный браузер недоступен в настройках Work; внешний сценарий изучен по публичному HTML/web, без отправки заявки и загрузки фото.
2. https://www.klotz.mobi/energiesparrechner — HTTP 200. Исходные поля: старое/новое окно, площадь, Öl/Erdgas/Strom, Gradtagzahl 3239 и Wirkungsgrad 0.75, дополнительные cooling-поля. Числа старых Uw: 4.72/2.84/4.93/2.85/5.83/3.49; новых: 1.2/0.95/1.21/0.85/1.1/0.8. В новой версии отдельные исходные числа используются только как редактируемые Rechenbeispiele; они не идентифицируют реальную конструкцию и не подтверждают текущий ассортимент. Неясная cooling-модель не переносится.
3. https://www.ift-rosenheim.de/2013/din-en-14351-1-produktnorm-fuer-fenster-und-aussentueren — Uw относится к целому окну; Ug не является его заменой. Исторические ссылки на нормы/EnEV не используются как актуальные правовые требования.
4. https://passipedia.de/planung/energieeffizienz_ist_berechenbar/energiebilanzen_mit_dem_phpp/monatsv — связь теплопотерь, площади, U и градусо-часов; полноценный баланс также учитывает период/теплопоступления. Наш линейный расчёт не называется PHPP или нормативным энергоаудитом.
5. https://www.dwd.de/DE/leistungen/gtz_kostenfrei/gtz_kostenfrei.html и https://www.dwd.de/DE/leistungen/klimastatusbericht/publikationen/ksb2008_pdf/a8g_2008.pdf?__blob=publicationFile&v=1 — определение G20/15 и климатические данные. DWD напрямую возвращает 403, определение доступно официальному поисковому индексу. 3239 взято из legacy и явно не названо фактическим значением Merseburg.

## Модель и границы

ΔQ = (Uw alt − Uw neu) × A × G × 24 / 1000 [kWh/a]. Положительная разница — уменьшение трансмиссии. При равном/большем новом Uw экономия не заявляется. ΔE = ΔQ / η, для Wärmepumpe вместо η — введённая JAZ. Стоимость = ΔE × собственный Arbeitspreis €/kWh. Для Fernwärme коэффициент относится к выбранной границе расчёта; фиксированные расходы не включены. Любые коэффициенты — редактируемые примеры, не оценка установки.

Не включены солнечные/внутренние теплопоступления, воздухопроницаемость, вентиляция, монтажные мостики, охлаждение и взаимодействие всего здания. Сохраняются noindex, пустой sitemap и отсутствие отправки/хранения заявки. Новых зависимостей нет. До явного клика нет внешних runtime-запросов. При загрузке Vollmodus iframe подключается к HTTPS-origin производителя; CSP допускает только этот frame-origin только для /konfigurator. Каталог/фото с provenance и правами только для презентации; публичное лицензирование третьих лиц открыто. Размерная SVG — оригинальная условная графика в коде.
